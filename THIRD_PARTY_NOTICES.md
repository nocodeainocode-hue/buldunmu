# Third-Party Data Notices

## Turkey Administrative Divisions

The `catalog:sync-districts` command retrieves district names from
[`open-admin-data/turkey-administrative-divisions`](https://github.com/open-admin-data/turkey-administrative-divisions),
commit `6dfe36b4360c4395656edc2ea0730224d269bc86`.

Copyright (c) 2026 jakkrapongt. The source data is licensed under the
[Creative Commons Attribution 4.0 International License](https://creativecommons.org/licenses/by/4.0/).
The application transforms the source records into city, district name, and slug fields.

## Turkey Province Boundaries

`public/data/turkey-provinces.geojson` contains the simplified ADM1 boundary
geometry for Türkiye from [geoBoundaries](https://www.geoboundaries.org/),
revision [`9469f09`](https://github.com/wmgeolab/geoBoundaries/tree/9469f09/releaseData/gbOpen/TUR/ADM1).
The geoBoundaries open dataset is offered under the
[Creative Commons Attribution 4.0 International License](https://creativecommons.org/licenses/by/4.0/).
The source record attributes the underlying geometry to OpenStreetMap contributors.
